# Model weights

Download `weights.pt` from [release v0.5.0](https://github.com/jdong745/merger-transformer/releases/tag/v0.5.0) into this directory. It contains the selected extended-window width-224 STEP064000 `float64` EMA inference tensors (`2,564,276` parameters), exact `518` two-sided bump spline knots (`[-1620, 160]M`), and model metadata. Weights are MIT licensed (see `LICENSE`) and attached to the release rather than tracked in Git.
