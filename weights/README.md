# Model weights

Download `weights.pt` from [release v0.2.1](https://github.com/jdong745/merger-transformer/releases/tag/v0.2.1) into this directory. It contains only the selected constant-low-learning-rate STEP048000 EMA inference tensors, spline knots, and model metadata. The weights are MIT licensed; see LICENSE. They are attached to the release rather than tracked in Git.
